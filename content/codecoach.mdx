## overview

Two classmates and I built Code Coach as our senior design project for the University of Michigan–Dearborn ACM chapter. It brings contest problems, an in-browser editor, code execution, and AI help into one place.

I worked on the interface and the application flows connecting it to the backend.


<ProjectFigure src="/projects/cc-home-screen.webp" alt="Code Coach practice and interview preparation home page" width={1440} height={930} kind="screen" />

## the workspace

Students can browse ICPC and interview practice problems, write and run a solution, and ask for help alongside their code. The assistant receives the problem and the student's solution so its feedback has context.

We also built an interview-preparation area with a resume builder.

## implementation

The frontend uses React and MUI. API Gateway routes requests to AWS Lambda, MongoDB stores application data, and Judge0 handles code execution.

The AI integration uses the university's U-M Maizey service. The [repository](https://github.com/d-pap/codecoach) includes the project setup and architecture.
