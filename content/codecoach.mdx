Two classmates and I built Code Coach as our senior design project for the University of Michigan–Dearborn ACM chapter. It brings contest problems, an in-browser editor, code execution, and AI help into one place. I worked on the interface and the application flows that connect it to the backend.

## the workspace

Students browse ICPC and interview practice problems, write and run a solution, and ask for help next to their code. The assistant receives the problem and the student's solution, so its feedback has context. We also built an interview-preparation area with a resume builder.

## implementation

The frontend uses React. API Gateway routes requests to AWS Lambda, MongoDB stores application data, and Judge0 runs the code. The AI help uses OpenAI API via the university's UMGPT service.
