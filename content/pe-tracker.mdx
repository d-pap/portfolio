I built PE Tracker to look up who owns a brand, including connections to private equity and other investment firms. It follows chains of parent companies and shows the sources behind each link.

I built the data pipeline and search interface so the records can be refreshed automatically.

## Following ownership chains

A brand can belong to a company that belongs to another company, with an investment firm several steps further up. PE Tracker follows those relationships through an ownership graph and presents the chain alongside dated sources.

Results distinguish private equity, other investment firms, and corporate ownership. Current control and ownership history are stored separately. Conflicting parent relationships stay visible with their supporting records.

## Reconciling public records

The Python pipeline collects claims from Wikipedia, Wikidata, OpenStreetMap's Name Suggestion Index, USDA FoodData Central, SEC filings, and FTC notices. Each source has its own collector, with shared records for entities, ownership claims, dates, and provenance.

The difficult part is matching businesses across sources. A shared identifier can join records directly; name matches need corroboration. The pipeline also distinguishes acquisitions and minority stakes from current control, and keeps earlier claims when a source changes.

## A pipeline behind a static site

The frontend is plain JavaScript and CSS. The pipeline produces static data and a search index, split into small files so a lookup loads only the records it needs.

Before publishing, the build checks known reference cases, claim counts, and shifts in ownership classifications. A failed check blocks publication. If a collector fails, the pipeline keeps that source's previous records.

## Ongoing work

The first implementation covers national brands and their parent companies. Next are public deployment, automated refreshes, and local businesses.
