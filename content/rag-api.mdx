## overview

Sprout is an AI health coach inside [RENEW](/work/renew-app). It helps people work through wellness goals and the day-to-day challenges of living with scleroderma.

I joined Michigan Medicine in June 2025 to build the system behind those conversations. My work spans retrieval, conversation memory, the API, and evaluation.

## the system

A LangGraph pipeline decides whether a message needs supporting information, retrieves relevant sources, and generates a reply. For questions that need evidence, it searches clinical and patient-education material and includes citations. Other turns can stay conversational.

I combined vector search with keyword search, followed by reranking. During implementation, I found and corrected a ranking issue in the library's Reciprocal Rank Fusion implementation.

The coach also uses clinical and conversation summaries to carry context between sessions. I'm testing how well that memory handles corrections and whether inferred patterns actually improve later replies.

## evaluation

I build evaluations around specific questions: did the system retrieve useful sources? Does the reply answer the question? Did a summary invent or lose a fact? Does a correction survive into the next conversation?

The current work uses DeepEval, fixed conversation cases, and comparisons with and without different sources of context. I inspect the saved responses alongside the scores; an automated judge can miss problems or flag the wrong thing.

The research is ongoing. In particular, we are still testing what retrieval and longer-term memory contribute to the coaching experience.

## implementation

The API runs on FastAPI with PostgreSQL and pgvector. LangGraph manages the conversation flow, and model requests go through the university's gateway. I maintain the service on a university Linux server.

The code is private to Michigan Medicine.
