Sprout is an AI health coach inside [RENEW](/work/renew-app). It helps people with scleroderma work through wellness goals and day-to-day challenges. I joined Michigan Medicine in June 2025 to build the system behind those conversations: retrieval, conversation memory, the API, and evaluation.

## the system

Each message is classified first. Questions that need evidence go through search over clinical and patient-education material, and the reply cites its sources. Other turns stay conversational.

Search combines vector and keyword retrieval, then reranks the results before the reply is written.

## memory

The coach carries context between sessions through clinical and conversation summaries. I'm testing how well that memory handles corrections, and whether patterns it infers improve later replies.

## evaluation

Each evaluation is built around a specific question. The current work uses DeepEval, fixed conversation cases, and comparisons with and without different sources of context. I read the saved responses alongside the scores, because an automated judge can miss problems.

<Figure caption="what the evaluations check">
  <EvalChecks />
</Figure>

The research is ongoing. We are still testing what retrieval and longer-term memory add to the coaching.

## implementation

The API runs on FastAPI with PostgreSQL and pgvector. LangGraph manages the conversation flow, and model requests go through the university's gateway. I maintain the service on a university Linux server.
