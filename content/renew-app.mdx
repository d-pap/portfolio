## overview

RENEW helps people living with scleroderma set wellness goals, track how they're feeling, and work through lessons on fatigue self-management. It also includes [Sprout](/work/rag-api), the AI health coach I work on.

I took over the app in September 2025. My work covers the React Native app, its PHP backend, the research admin portal, and releases.

## what I've changed

I upgraded the React Native and Expo codebase and replaced one-off styling with shared components and typed design tokens. That gives the app consistent spacing, typography, color, and motion without adjusting every screen separately.

I've been redesigning the daily check-in, goals, learning modules, and profile. The details matter here: keeping unfinished goals easy to find, returning people to the lesson they were reading, and making an edited check-in feel immediate.

I also replaced the magic-link login flow with email codes and consolidated authentication checks across the API.

## the research tools

The team needs to manage the study as well as support participants. I built a workflow in the admin portal for importing assessment data, reviewing generated clinical summaries, and saving them for the health coach to use.

The researcher maps each upload to participants explicitly. That keeps the mapping visible and reviewable before a summary is saved.

## implementation

The app uses React Native, Expo, TypeScript, TanStack Query, and Zustand. The backend is PHP and MySQL on Michigan Medicine servers. I use Jest and React Native Testing Library for app tests, and EAS for mobile builds.

For server changes, I wrote deployment scripts with a preview mode and timestamped backups. App changes move through development and TestFlight; the redesign is ongoing, and the public release doesn't yet include every screen described here.

The source code is private. [RENEW is available on the App Store](https://apps.apple.com/us/app/renew-scleroderma/id1579955473).
